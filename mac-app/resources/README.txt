Doc Weather Liaison Mac App
===========================

This desktop app:
- Embeds your Railway dashboard (control room)
- Points at ~/Desktop/Doc Weather Content
- Can start the local Python agent for folder watching + posting

Build a downloadable .app / .dmg:
  cd ~/social-media-liaison/mac-app
  npm install
  npm run dist

Output:
  dist/Doc Weather Liaison-1.0.0.dmg
  dist/mac/Doc Weather Liaison.app
